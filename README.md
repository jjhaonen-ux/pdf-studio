# محرر PDF المحلي — النسخة الأولى MVP (v1.0.0)

تطبيق ويب مبني بـ **Next.js + TypeScript + Tailwind CSS** لدمج وتعديل ملفات PDF محلياً داخل المتصفح بخصوصية كاملة، دون رفع أي مستند إلى خادم.

## ملخص المراحل المكتملة (1 → 5)

1. **المرحلة 1 — التأسيس والأمان:** بنية معمارية تفصل سجل العمليات عن الملفات الأصلية، دعم RTL كامل، والتحقق الأمني من الملفات عبر التوقيع الثنائي (`%PDF-`).
2. **المرحلة 2 — الدمج وإدارة الصفحات:** رفع متعدد بالسحب والإفلات، إعادة ترتيب الملفات والصفحات، نطاقات صفحات مخصصة (مع الأرقام العربية `١-٥، ٨`)، مصغّرات كسولة عبر `PDF.js`، تدوير وحذف واستعادة.
3. **المرحلة 3 — المحرر التفاعلي:** إضافة النصوص والصور ولوحة التوقيع (رسم بالماوس/اللمس مع قص تلقائي وحفظ في الجلسة)، التحكم بالحجم واللون والشفافية والخلفية البيضاء، التكبير (`50%–225%`)، تحويل الإحداثيات لجميع زوايا التدوير، وتراجع وإعادة موحّد (`Ctrl+Z / Ctrl+Y`).
4. **المرحلة 4 — العربية والأداء والذاكرة:** تضمين خطي `DejaVuSans.ttf` و`DejaVuSans-Bold.ttf` عبر `@pdf-lib/fontkit` مع محرك تشكيل عربي و`BiDi`، نقل التصدير إلى `Web Worker` مع شريط تقدم وإلغاء فوري، كاش `LRU` للمصغرات، ومراقبة الذاكرة.
5. **المرحلة 5 — التحصين والاختبار والإطلاق:**
   - تصنيف أخطاء الملفات التالفة والمشفرة والفارغة مع اقتراحات عملية و`ErrorBoundary` شامل وحماية `beforeunload`.
   - **التحقق التلقائي من الملف الناتج (`verifyExportedPdf`)** قبل التنزيل للتأكد من سلامة بنيته وتطابق عدد صفحاته.
   - اختبارات تكامل شاملة عبر **Playwright** (سطح المكتب + الهاتف + التحقق من عدم تسرب أي ملف للشبكة) ومولّد ملفات عيّنة (`scripts/generate-test-samples.mjs`).
   - نافذة **الخصوصية وفحص توافق المتصفح ونسخ التشخيص**، ترويسات أمان HTTP، وملفات الجاهزية للنشر (`CI` + `vercel.json` + `LAUNCH_CHECKLIST.md`).

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

## الأوامر المتاحة للاختبار والتحقق

```bash
# فحص الأنواع + ESLint + اختبارات Vitest + بناء الإنتاج
npm run verify

# تشغيل اختبارات الوحدة فقط
npm test

# توليد 5 ملفات اختبار (سليم، مدوّر، مزيف، تالف، مشفّر) في test-samples/
npm run generate:samples

# تشغيل اختبارات Playwright (تحتاج npx playwright install لأول مرة)
npm run test:e2e
```

## النشر السريع (نسخة تجريبية)

اربط المستودع بمنصة **Vercel** (ملف `vercel.json` جاهز) أو شغّل `npm run build && npm start` على أي استضافة Node.js تدعم HTTPS. راجع `LAUNCH_CHECKLIST.md` قبل الإطلاق العام.
